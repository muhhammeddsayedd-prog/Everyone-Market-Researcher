# Component specifications

This catalogue is extracted from [DESIGN.md](DESIGN.md), section 6. It preserves the original anatomy, states and Market Radar data references. These are specifications to implement in the destination app, not exported React components.

For another app, replace entity names, route and schema references, review permissions and keyboard shortcuts with that product's requirements. Use [REUSE_GUIDE.md](REUSE_GUIDE.md) for theme contrast, accessibility and integration caveats. In particular, adapt the primary-button fill/text pair for light mode.

## Original catalogue

Each component lives in `apps/web/components/ui/` (primitives) or `components/features/` (domain). Every component: typed props, `className` passthrough, a forwarded ref where interactive, a Storybook-style example on the `/dev/components` page (dev only).
